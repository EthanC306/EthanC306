## Projects

### Codenames Turing Test

Undergraduate research exploring whether humans can distinguish between human and LLM teammates in the game **Codenames**.

- Built on an existing Go-based Codenames implementation
- Integrated LLM players capable of acting as both spymasters and operatives
- Supports randomized human/AI team compositions
- Collects gameplay data and participant predictions for human-vs-AI analysis
- Experimenting with locally hosted LLMs for game reasoning

`Go` `LLMs` `AI Evaluation` `Human-AI Interaction`

---

### SkillTape

A self-hosted computer science study platform built to make active recall and spaced repetition more useful for technical subjects.

- Multiple study modes including quizzes, flashcards, drills, and visualizations
- Spaced-repetition scheduling for targeted review
- Local AI-powered grading
- Tracks progress and mastery across topics
- Packaged as a desktop application with automatic updates

`React` `Express` `SQLite` `Electron` `Docker` `LLMs`

---

### OU Dining Tracker

A full-stack web application for exploring Ohio University dining hall menus and nutritional information.

- Built with **React, Node.js, Express, SQLite, and Puppeteer**
- Scrapes menu and nutrition data from **13 OU dining locations**
- Designed an idempotent scraping pipeline for reliable daily data collection
- Built a date and meal-based database structure for querying current offerings
- Includes search, data deduplication, and persistent client-side preferences

`React` `Node.js` `Express` `SQLite` `Puppeteer`
